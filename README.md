# 公司行为驱动的行情复权与历史价格修正服务

基于 Spring Boot 3 / Java 17 的 HTTP 服务。统一登记拆股、合并（缩股）、
分红、配股等公司行为，并对原始收盘价序列计算未复权 / 前复权 / 后复权三种口径价格。

## 事件类型与参数

请求体中 `params.kind` 标识事件类型，参数非法时返回 `400 INVALID_PARAM`：

| 类型 | kind | 参数 | 约束 |
| --- | --- | --- | --- |
| 拆股 | `SPLIT` | `ratio`（新股/旧股） | 必须 > 1（如 10 送 10 填 `2`） |
| 合并（缩股） | `MERGE` | `ratio`（新股/旧股） | 必须 0 < ratio < 1（如 10 合 1 填 `0.1`） |
| 现金分红 | `DIVIDEND` | `perShare`（每股红利，税前） | 必须 > 0 |
| 配股 | `RIGHTS_ISSUE` | `ratio`（配股比例）、`subscriptionPrice`（配股价） | 均必须 > 0 |

## 复权口径与因子定义

以价格序列**首个交易日**为基准日（后复权因子 = 1），因子在事件生效日
（除权除息日）当日及之后生效。单个事件的日因子 r：

- 拆股 / 合并：`r = ratio`
- 分红：`r = P / (P - d)`，P 为生效日前最后一个交易日的原始收盘价，d 为每股红利。
  除权参考价为 `P - d`，后复权因子把除权日价格抬回除权前水平。
- 配股：`r = P / ref`，其中除权参考价 `ref = (P + s·p) / (1 + s)`，
  s 为配股比例、p 为配股价，参考价按最小价格单位四舍五入。

累计后复权因子 `F(t) = ∏ rᵢ`（所有生效日不晚于 t 的事件连乘）。

早于价格序列首个交易日的事件（已反映在原始价格中）不参与复权计算，以保证首日因子为 1。

- **未复权（RAW）**：原始收盘价。
- **后复权（BACKWARD）**：`raw × F(t)`，以序列起点为基准，越早的价格被调整得越低/越高，
  最新价格与原始价格之间体现全部历史事件。
- **前复权（FORWARD）**：`raw × F(t) / F(最新日)`，以序列最新交易日为锚，最新价等于原始价。

所有除法固定 34 位精度、`HALF_UP`；因子保留 12 位小数输出；前/后复权**展示价**
按价格最小变动单位（`corporate-actions.tick`，默认 0.01）四舍五入。
因此逐条应用事件与整体重放的因子**逐位一致**，前后复权换算误差不超过一个最小价格单位，
且误差不随事件数量累积。

## 语义保证

- **乱序登记**：事件按 `effectiveDate` 排序应用（同日再按事件 ID 排序），
  同一批事件以任意顺序登记结果完全一致。
- **修正 / 撤销**：`PUT` 修改或 `DELETE` 撤销后，因子与历史价格整体重算，
  等价于从零重放修正后的事件序列。
- **重复防护**：同一标的、同一日期、同一类型、相同参数的事件返回
  `409 DUPLICATE_EVENT`，不重复生效。
- **冲突防护**：同一标的同一生效日存在不同事件时返回
  `409 CONFLICTING_EVENT`（错误码与重复可区分）；不同标的互不影响。
- **并发一致性**：登记/修正/撤销使用写锁，查询使用读锁并基于不可变快照计算，
  查询只能观察到事件应用前或应用后的完整状态。
- **重启恢复**：每次变更以「临时文件 + 原子替换」写入
  `corporate-actions.data-file`，启动时整体加载，重启后不丢失、不重复应用事件。

## 除权除息连续性保证

分红与配股事件按标准除权除息语义调整，保证价格序列在除权除息日前后连续：

- **现金分红**：设生效日前一交易日收盘价为 `P`，每股分红为 `d`。
  后复权口径下生效日价格 = `P`（与前一交易日完全连续）；
  前复权口径下生效日前一交易日价格 = `P - d`（与生效日未复权价一致）。
  未复权口径保持原始价格不变。
- **配股**：设生效日前一交易日收盘价为 `P`，配股比例为 `s`，配股价为 `p`。
  除权参考价 `ref = (P + s·p) / (1 + s)`（按最小价格单位四舍五入）。
  当生效日未复权收盘价等于 `ref` 时，后复权口径下生效日价格回到 `P`，
  前复权口径下生效日前一交易日价格 = `ref`，允许误差不超过一个最小价格单位。
- **价差不等式**：对分红与配股事件，在生效日之后出现的第一个行情点与
  生效日之前最后一个行情点之间，前复权与后复权各自的价差绝对值均不得超过
  同一区间未复权价差的绝对值。当生效日未复权价恰好等于除权除息参考价时，
  前复权与后复权序列在该区间完全连续（价差不超过一个最小价格单位）。
- **多事件叠加**：多个分红与配股事件按生效日先后叠加时，每个除权除息区间
  都满足各自的连续性要求；任意交易日三种口径之间的换算误差不超过一个
  最小价格单位，且不随事件数量增长而扩大。

### 可手工核对的数值示例

**现金分红**：前收盘 10.00 元，每股分红 1.00 元，生效日收盘 9.00 元。

| 口径 | 生效日前一日 | 生效日 |
| --- | --- | --- |
| 未复权 | 10.00 | 9.00 |
| 后复权 | 10.00 | 10.00 |
| 前复权 | 9.00 | 9.00 |

**配股**：前收盘 10.00 元，每 10 股配 3 股，配股价 6.00 元。

除权参考价 = (10 + 0.3 × 6) / 1.3 = 9.0769 → 四舍五入 9.08 元。

| 口径 | 生效日前一日 | 生效日 |
| --- | --- | --- |
| 未复权 | 10.00 | 9.08 |
| 后复权 | 10.00 | 10.00（允许 ±0.01 误差） |
| 前复权 | 9.08（允许 ±0.01 误差） | 9.08 |

```bash
# 录入行情
curl -X POST http://localhost:8080/api/prices \
  -H 'Content-Type: application/json' \
  -d '{"symbol":"600000","points":[
    {"date":"2024-03-01","close":10.00},
    {"date":"2024-03-04","close":9.00}
  ]}'

# 登记分红
curl -X POST http://localhost:8080/api/actions \
  -H 'Content-Type: application/json' \
  -d '{"symbol":"600000","effectiveDate":"2024-03-04",
       "params":{"kind":"DIVIDEND","perShare":1.00}}'

# 查询三口径（后复权生效日价应为 10.00，前复权前一日价应为 9.00）
curl 'http://localhost:8080/api/prices/600000?view=ALL'
```

## 异常场景处理

分红与配股事件在登记时不强制校验行情数据（行情可能补录），但在价格查询时
会校验数据合法性。查询返回明确且可区分的错误码，不返回负数价格、零价格或
内部异常，不影响其他标的或该标的其他口径的查询。

| 场景 | 错误码 | HTTP | 说明 |
| --- | --- | --- | --- |
| 生效日之前不存在任何收盘价 | `INSUFFICIENT_PRICE_HISTORY` | 400 | 无法计算除权因子 |
| 每股红利大于等于前收盘价 | `INVALID_DIVIDEND` | 400 | 除权参考价非正，因子无意义 |

- **隔离性**：错误仅影响该标的的复权口径查询；其他标的的查询正常。
  同一标的的 `RAW` 口径不依赖复权因子，仍可返回原始价格（复权字段为空）。
- **恢复**：后续补录生效日之前的历史价格，或修正分红金额使除权参考价恢复
  合法后，查询自动恢复为正确结果，无需重启。
- **登记与撤销一致性**：登记时接受事件（不预校验行情），查询时校验；
  撤销后事件移除，查询恢复正常。登记与撤销行为一致，错误码与消息可区分。

## HTTP 接口

### 登记事件

```http
POST /api/actions
{
  "symbol": "600000",
  "effectiveDate": "2024-03-01",
  "params": { "kind": "SPLIT", "ratio": 2 }
}
```

成功返回 `201` 与含 `id` 的事件；`PUT /api/actions/{id}` 修正；
`DELETE /api/actions/{id}` 撤销；`GET /api/actions?symbol=` 查询事件。

### 录入原始价格

```http
POST /api/prices
{
  "symbol": "600000",
  "points": [
    {"date": "2024-02-28", "close": 10.00},
    {"date": "2024-03-01", "close": 5.20}
  ]
}
```

同一 `(symbol, date)` 重复录入按覆盖处理。

### 查询复权价格

```http
GET /api/prices/600000?view=ALL&from=2024-01-01&to=2024-06-30
```

`view` 取 `ALL`（默认，同时返回三种口径）、`RAW`、`FORWARD`、`BACKWARD`。
每个数据点包含 `date / raw / forward / backward / factor`。
分红与配股事件要求生效日之前至少存在一个原始收盘价，否则返回 `400 INVALID_PARAM`。

### 错误码

| HTTP | code | 含义 |
| --- | --- | --- |
| 400 | `INVALID_PARAM` | 参数缺失/非法 |
| 400 | `INSUFFICIENT_PRICE_HISTORY` | 分红/配股事件生效日之前不存在任何收盘价 |
| 400 | `INVALID_DIVIDEND` | 每股红利大于等于前收盘价，除权参考价非正 |
| 404 | `NOT_FOUND` | 修改/撤销的事件 ID 不存在 |
| 409 | `DUPLICATE_EVENT` | 完全相同的事件重复登记 |
| 409 | `CONFLICTING_EVENT` | 同标的同日期存在不同事件 |
