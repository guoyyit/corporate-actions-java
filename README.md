# 公司行为驱动的行情复权与历史价格修正服务

基于 Spring Boot 3 / Java 17 的 HTTP 服务。统一登记拆股、合并（缩股）、
分红、配股等公司行为，并对原始收盘价序列计算未复权 / 前复权 / 后复权三种口径价格。

## 事件类型与参数

请求体中 `params.kind` 标识事件类型，参数非法时返回 `400 INVALID_PARAM`：

| 类型 | kind | 参数 | 约束 |
| --- | --- | --- | --- |
| 拆股 | `SPLIT` | `ratio`（新股/旧股） | 必须 > 1（如 10 送 10 填 `2`） |
| 合并（缩股） | `MERGE` | `ratio`（新股/旧股） | 必须 0 < ratio < 1（如 10 合 1 填 `0.1`） |
| 现金分红 | `DIVIDEND` | `perShare`（每股红利，税前） | 必须 > 0 |
| 配股 | `RIGHTS_ISSUE` | `ratio`（配股比例）、`subscriptionPrice`（配股价） | 均必须 > 0 |

## 复权口径与因子定义

以价格序列**首个交易日**为基准日（后复权因子 = 1），因子在事件生效日
（除权除息日）当日及之后生效。单个事件的日因子 r：

- 拆股 / 合并：`r = ratio`
- 分红：`r = P / (P - d)`，P 为生效日前最后一个交易日的原始收盘价，
  d 为每股红利；除息参考价为 `P - d`
- 配股：`r = P·(1+s) / (P + s·p)`，s 为配股比例、p 为配股价；
  除权参考价为 `(P + s·p) / (1+s)`

累计后复权因子 `F(t) = ∏ rᵢ`（所有生效日不晚于 t 的事件连乘）。

早于价格序列首个交易日的事件（已反映在原始价格中）不参与复权计算，以保证首日因子为 1。

- **未复权（RAW）**：原始收盘价。
- **后复权（BACKWARD）**：`raw × F(t)`，以序列起点为基准，除权除息日之前的价格
  保持不变，之后的价格被调回除权前水平，最新价格与原始价格之间体现全部历史事件。
- **前复权（FORWARD）**：`raw × F(t) / F(最新日)`，以序列最新交易日为锚，最新价等于原始价。

所有除法固定 34 位精度、`HALF_UP`；因子保留 12 位小数输出；前/后复权**展示价**
按价格最小变动单位（`corporate-actions.tick`，默认 0.01）四舍五入。
因此逐条应用事件与整体重放的因子**逐位一致**，前后复权换算误差不超过一个最小价格单位，
且误差不随事件数量累积。

### 分红与配股的连续性保证

分红与配股在除权除息日压低市场价格，复权口径必须消除这一跳空而非放大它：

- 当生效日未复权收盘价等于除权除息参考价时，前复权与后复权序列在
  「生效日前最后一个行情点 → 生效日起第一个行情点」区间**完全连续**，
  复权价差不超过一个最小价格单位。
- 一般情况下，上述区间内前复权与后复权各自的价差绝对值均不超过
  同一区间的未复权价差绝对值。
- 多个分红 / 配股事件按生效日先后叠加时，每个除权除息区间各自满足
  上述连续性要求，任意交易日三种口径之间的换算误差不超过一个最小价格单位，
  且不随事件数量增长而扩大。

**可手工核对的数值示例**

现金分红：前收盘 10.00 元，每股分红 1.00 元，除息日收盘 9.00 元
（恰为除息参考价 10.00 − 1.00）：

| 日期 | 未复权 | 前复权 | 后复权 |
| --- | --- | --- | --- |
| 除息日前一日 | 10.00 | 9.00（= 10.00 × 9/10） | 10.00 |
| 除息日 | 9.00 | 9.00 | 10.00（= 9.00 × 10/9） |

配股：前收盘 10.00 元，每 10 股配 3 股（s = 0.3），配股价 6.00 元。
除权参考价 = (10.00 + 0.3 × 6.00) / 1.3 ≈ 9.0769，按最小价格单位
四舍五入为 9.08 元，除权日收盘 9.08 元：

| 日期 | 未复权 | 前复权 | 后复权 |
| --- | --- | --- | --- |
| 除权日前一日 | 10.00 | 9.08（= 10.00 × 11.8/13 ≈ 9.0769） | 10.00 |
| 除权日 | 9.08 | 9.08 | 10.00（= 9.08 × 13/11.8 ≈ 10.0034） |

验证方法：登记事件与价格后查询
`GET /api/prices/{symbol}?view=ALL`，检查相邻两点复权价差不超过 0.01，
且后复权价 ≈ 未复权价 × factor、前复权价 ≈ 后复权价 ÷ 最新 factor
（误差均不超过一个最小价格单位）。

### 异常场景处理规则

以下两类数据不一致在**查询时**检测，返回 `422` 与可区分错误码，
不会返回负数价格、零价格或内部异常：

- `MISSING_PRECEDING_CLOSE`：分红 / 配股事件生效日之前不存在任何原始收盘价，
  无法确定除权基准价。
- `DIVIDEND_EXCEEDS_PREVIOUS_CLOSE`：每股红利大于等于前收盘价，
  除息后价格将为零或负数。

一致性约定（登记 / 撤销 / 查询）：

- **登记与修正**只做结构校验（参数为正数等），不检查价格数据；
  因为事件是否合法取决于价格，而价格可能后补。
- **撤销**始终可用，撤销非法事件后查询立即恢复。
- **查询**按当前事件与价格快照实时计算：补录或修正历史价格使场景
  恢复合法后，查询自动恢复为正确结果，无需重新登记事件。
- 数据不一致只影响该标的的复权口径（`ALL` / `FORWARD` / `BACKWARD`）；
  **未复权（RAW）口径不受影响**，仍返回原始价格（此时 factor 置 1、
  前后复权字段以原始价占位）；其他标的的查询完全不受影响。

## 语义保证

- **乱序登记**：事件按 `effectiveDate` 排序应用（同日再按事件 ID 排序），
  同一批事件以任意顺序登记结果完全一致。
- **修正 / 撤销**：`PUT` 修改或 `DELETE` 撤销后，因子与历史价格整体重算，
  等价于从零重放修正后的事件序列。
- **重复防护**：同一标的、同一日期、同一类型、相同参数的事件返回
  `409 DUPLICATE_EVENT`，不重复生效。
- **冲突防护**：同一标的同一生效日存在不同事件时返回
  `409 CONFLICTING_EVENT`（错误码与重复可区分）；不同标的互不影响。
- **并发一致性**：登记/修正/撤销使用写锁，查询使用读锁并基于不可变快照计算，
  查询只能观察到事件应用前或应用后的完整状态。
- **重启恢复**：每次变更以「临时文件 + 原子替换」写入
  `corporate-actions.data-file`，启动时整体加载，重启后不丢失、不重复应用事件。

## HTTP 接口

### 登记事件

```http
POST /api/actions
{
  "symbol": "600000",
  "effectiveDate": "2024-03-01",
  "params": { "kind": "SPLIT", "ratio": 2 }
}
```

成功返回 `201` 与含 `id` 的事件；`PUT /api/actions/{id}` 修正；
`DELETE /api/actions/{id}` 撤销；`GET /api/actions?symbol=` 查询事件。

### 录入原始价格

```http
POST /api/prices
{
  "symbol": "600000",
  "points": [
    {"date": "2024-02-28", "close": 10.00},
    {"date": "2024-03-01", "close": 5.20}
  ]
}
```

同一 `(symbol, date)` 重复录入按覆盖处理。

### 查询复权价格

```http
GET /api/prices/600000?view=ALL&from=2024-01-01&to=2024-06-30
```

`view` 取 `ALL`（默认，同时返回三种口径）、`RAW`、`FORWARD`、`BACKWARD`。
每个数据点包含 `date / raw / forward / backward / factor`。
分红与配股事件要求生效日之前至少存在一个原始收盘价、且每股红利小于前收盘价，
否则复权口径查询返回 `422`（详见「异常场景处理规则」）。

### 错误码

| HTTP | code | 含义 |
| --- | --- | --- |
| 400 | `INVALID_PARAM` | 参数缺失/非法 |
| 404 | `NOT_FOUND` | 修改/撤销的事件 ID 不存在 |
| 409 | `DUPLICATE_EVENT` | 完全相同的事件重复登记 |
| 409 | `CONFLICTING_EVENT` | 同标的同日期存在不同事件 |
| 422 | `MISSING_PRECEDING_CLOSE` | 分红/配股生效日之前没有任何原始收盘价 |
| 422 | `DIVIDEND_EXCEEDS_PREVIOUS_CLOSE` | 每股红利大于等于前收盘价 |
